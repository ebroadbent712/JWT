# Just Wear This for Claude

This is the Just Wear This plugin store. Add it in Claude under Customize → Plugins → Add marketplace
(`ebroadbent712/JWT`), then install **Just Wear This**. In Claude Code:
`/plugin install just-wear-this --marketplace ebroadbent712/JWT`. Updates arrive through Check for updates (or turn on Sync automatically).
